# Architecture

Diagramas e decisões de arquitetura que atravessam mais de um domínio (ex.: por que o
motor é genérico, por que domínios não se conhecem, decisões sobre o formato do
envelope de evento). Decisões específicas de um domínio ficam no README dele
(`domains/<nome>/README.md`), não aqui.

Ainda vazio -- primeiro candidato a entrar aqui é o diagrama de "um processo por domínio
vs. um processo compartilhado" mencionado na conversa que gerou essa reorganização.
